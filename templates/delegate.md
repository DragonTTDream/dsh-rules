# 委派单（delegate）

> 复制本模板，三段填满再派。**三段缺一段就不派**（R-15）。
> 派之前先答一句：这件事主对话自己做，会往上下文里塞多少原文？
> 塞得越多、回传越少，派出去越划算（判据 = 读入量 ÷ 回传量）。
> 反例：**派出去再让子代理"顺便看看还有什么问题"** —— 那是把判断权外包，R-15 禁止。

## ① 范围

- 看：<文件/目录/命令，写绝对路径或仓内相对路径，逐条列>
- 不看：<明确排除的东西，防止它顺手扩大范围>
- 边界：**只读**，不许改 / **可改这些**：<列>

## ② 判据

<什么算对。要能二值回答，不许写"检查是否合理">
- 例：`grep -c 'disable-model-invocation' <file>` 必须为 1
- 例：同一结论在 ≥2 个不同文件里都能找到出处

## ③ 输出

- **结论**：一张表，列固定为 <列1 | 列2 | 列3>
- **来源**：每条结论后跟 `文件:行` 或命令输出的关键行
- **未决**：没查清的一次性列全；没有就写「无」
- **schema**（调用方支持 outputSchema 时）：
  ```json
  { "conclusions": [{ "claim": "", "source": "" }], "open": [] }
  ```
