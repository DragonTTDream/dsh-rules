## 规则

- 任何改动（写 / 移 / 删 / 重启 / 安装 / 跨范围操作）**先说后动**，等用户在对话里点头。
- **只做被明确点名的事。** "顺手精简 / 顺手统一"必须先问。
- 涉及使用体验的机制（鉴权 / 登录 / 确认步骤 / 额外门槛）先说先问，绝不自行加。
- 会掐断当前会话的操作（重启宿主服务）必须事先告知恢复方式。
- 删除前逐个核对绝对路径；只删本次产生的或用户点名的；
  拿不准的进隔离区等用户决定，不强删。

### 怎么判

把要动的每条文件/服务列出来，逐条问：这一条被用户点过名吗？没有 → 先问。
