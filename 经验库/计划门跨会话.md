# 计划门跨会话：别的会话的 draft 把我拦住

## 症状

- 本会话明明没有未定稿的方案，写文件却被拒："方案还没定稿（`~/.dsh/plans/active.md` 里 status: draft）"
- 换个会话还一样
- 更糟：**想把守卫改成按会话隔离，改它的那次写操作也被它拦住**（鸡生蛋）

## 判据

- `~/.dsh/plans/active.md` 存在，且 `status` 不是有效批准
- 该文件是**别的任务/会话**留下的（内容对不上你当前在做的事）
- 守卫报错里带着**全局单文件路径**

## 根因（2026-10-22 实测）

三件事叠在一起：

1. 计划文件是**全局单文件** `~/.dsh/plans/active.md` —— 没有会话归属
2. 判定"有效批准"要求 `approved_at` + `approved_msg` 齐全；**缺 `approved_at` 就算 draft**
3. 守卫对 shell 命令用**命令文本粗匹配**（`rm` / `mv` / `git commit` …），
   连"在 python 里写代码包含这些字符串"都会被判成改盘

## 正解骨架

1. **计划加会话字段**，跨会话不再互相拦：
   ```yaml
   ---
   status: approved
   session: <会话 id>
   approved_at: 2026-10-22T03:30:00Z
   approved_msg: <用户逐字原话>
   ---
   ```
2. **没有 `session` 字段的历史文件 ⇒ 不拦任何人**（避免全局卡死）
3. 残留文件归档而不是删：
   ```bash
   ~/.dsh/plans/active.md  →  ~/.dsh/plans/archive/active-<时间>-<任务名>.md
   ```

## 反例

- 把 status 改成 approved 硬闯 —— 伪造批准，且下次照样卡
- 直接删掉别人的计划文件 —— 丢了那次的方案与授权原文
- 用别的写法绕过命令文本匹配 —— 只是把死锁推迟到下一次

## 边界

只限**本机 dsh 的计划门实现**（`~/.dsh/plans/active.md` + 守卫 `planGate`）；别的 agent 框架没有这个文件。
不覆盖「同一会话内确实没定稿」的情形——那本来就该拦。
不覆盖「计划文件被写坏」：那是解析问题，判据是 `planState()` 的输出。
