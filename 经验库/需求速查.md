# 用户需求速查（任何新会话先读这一页）

> 目的：让任何人/AI 在 1 分钟内知道他要什么，不必从头聊。
> 维护：他纠正你一次，就往这里加一行；细节进同目录条目，这里只留判据。

## 一句话

他要的是**能迁移到新实例的纪律** + **能机器执行的拦截**，不是某个 bug 的来龙去脉。

## 他说这句 → 你别做什么 / 该做什么

| 他说的 | 别做 | 做 |
|---|---|---|
| 「要纪律性的，不是特定的」 | 讲这个 bug 怎么发生 | 写“换掉实例仍成立”的判据 + 可抄骨架 |
| 「最安全的改法是什么」 | 列 A/B 再问他选哪个 | 给推荐项并**直接做**；不可逆处才停 |
| 「重新测试」 | 云端/默认档跑一遍 | 他的模型 + `effort=max` + **带工具** + 真陷阱 |
| 「都好了吗」 | 先讲机制 | **先查覆盖**：哪条有、哪条没有 |
| 「批准」 | 问他默认项 / 降档执行 | 执行**推荐项**；重启另等他一句话 |
| 「经验落盘」 | 写事故故事 | 五段式：症状/判据/正解/反例/边界 |

## 他的环境事实（不用再问）

- 本地模型 `provider=llm`、`model=strata-swift-iq3xxs-256k`，平时 **`reasoningEffort=max`**
- 单槽 48GB：一次一条推理；重活走 `arbitrate_run`（≤900 s），子代理只省上下文不省时间
- 经验库：`~/.dsh/gotchas` → 仓库 `经验库/`；`INDEX.md` 是 grep 入口
- L0（`~/.dsh/AGENTS.md`）有 **14336 字节**硬闸门，合成超了就不许装
- **重启必须由他当轮消息明确授权**；上一轮的不结转

## 硬约束（违反过 = 返工）

1. **先说意图再动手**：一句话「我要做 X」，然后直接做。**不问双行道，也不闷声做完。**
2. **方案层不自决**；批准后按推荐项执行，不许降档（曾把他的“批准”做成我自己给的默认项）
3. **先取证再断言**；「毫秒级退出 + 零输出」= **启动失败**，不是崩溃
4. **测试必须真模型真档位**；云端冒充本地 = 无效样本
5. **成功判据不得由被检查的调用自报**（exit 0 / 日志 ok / 工具返回 success 都不算）
6. 不擅自重启/安装/删文件；不可逆动作逐条点名
7. 交付先给结论表，细节进档；不贴长文

## 他反复纠正过的四个错误（最容易再犯）

1. **答错轴**：他问“这类内容的要求”，我答“这个纪律叫什么”
2. **替他决定**：把方案层选项包装成“可逆的执行细节”自己拍板
3. **假测试**：用云端模型 + 默认档，还宣称“真实测试”
4. **问太多**：他已批准的范围内还在问“要我做吗”

## 判定他满不满意，看三个信号

- 结论能不能**指到一条命令输出/字节**（能 = 对）
- 条目能不能**换掉实例仍成立**（能 = 纪律，不是案例）
- 动作能不能**机器执行**（能 = 该下沉守卫；不能才留在经验库）
