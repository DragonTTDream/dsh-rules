# 取证探针自伤：读数稳如泰山，字段其实没读到

## 症状

- 采样器跑了上千次，输出「全部为 0 / 全部相同 / 无跳变」，而同一条命令的手工读数明明非零
- `awk '{print $2}'` 取 journal 的"时间"，比较结果全空或全命中（`$2` 是**日期里的"日"**，中文 locale 下时间在第 3 字段）
- 往远端喂 heredoc 脚本，正文里出现服务动词（restart/stop 一行命令），本地守卫把**这条本地命令**判成"要重启生产服务"并拦下
- `ss -lunp` 在非 root 下拿不到进程名，脚本按"名字匹配"分类 ⇒ 全部落进"其它/未知"，看起来像端口被别人占着

## 判据

- 采样器给出"恒定值"（全 0 或全同）⇒ **先假设探针坏了**，与已知量对拍（同一时刻手工读一次）再谈现象
- 解析带时间戳的行：**先打印 3 条原始样本的字段编号**，确认时间落在第几字段，再写比较
- 服务动词写进脚本正文 = 会触发本地守卫；取证脚本正文用**名词描述**（"对该单元下重启令"），要真下令时单独一步
- 需要进程归属的采样 ⇒ 用提权身份跑（`ss -lunp` 的进程名列只有 root 有）

## 正解

骨架（时间戳解析，先验字段再比较）：

```bash
journalctl -u <unit> --since "4 days ago" --no-pager -o short-iso | grep <事件> | head -3
# 看这 3 行里时间在第几个字段（short-iso: $1=日期 $2=时间+时区；默认格式中文 locale: $3=时间）
journalctl ... -o short-iso | grep <事件> | awk '{print $1, $2}' > /tmp/ts.txt
python3 - <<'PY'
import datetime as dt
ts=[dt.datetime.fromisoformat(a+"T"+b) for a,b in (l.split()[:2] for l in open('/tmp/ts.txt'))]
prev=None
for t in ts:
    if prev and (t-prev).total_seconds()>90: print("空窗", prev, t)
    prev=t
PY
```

骨架（端口在位采样，root + 与看守同一件仪器）：

```bash
sudo -n bash -c 'end=$((SECONDS+150)); f=0; h=0; \
while [ $SECONDS -lt $end ]; do \
  L=$(ss -lunp 2>/dev/null | awk "/:1900 /{print; exit}"); \
  [ -z "$L" ] && f=$((f+1)) || h=$((h+1)); sleep 0.25; \
done; echo free=$f held=$h'
```

## 反例

- 拿"16 143 次采样全部 min=0、transitions=0"当证据下结论"端口从未在位" —— 同一时刻 root 的 `ss` 采样 470/470 都在位；矛盾说明坏的是解析器（`split()[1]` 取错字段 / 非 root 读不到），不是现象
- 用中文 locale 的 journal 默认格式做 `$2>$x` 的时间比较，全部落空，然后判定"该窗口内没有事件"
- 非 root 跑 `ss -lunp` 并按进程名分类，把"看不见名字"记成"被别的程序占用"，再顺着这个假事实去找"谁抢了端口"

## 边界

- 适用：排障期的**采样/计数类探针**（journal 解析、/proc 解析、端口/进程归属采样）。
- 不适用：单发事实读数（一次 `ss -lunp`、一次 `ls -l`）——那类要先解决的是提权与字段，不是"恒定值=坏探针"。
- 探针"恒定值"与手工读数**一致**时，本条不适用，按现象本身继续。
