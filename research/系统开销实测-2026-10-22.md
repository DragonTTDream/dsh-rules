# 系统提示词与工具定义开销实测（2026-10-22）

> 目的：把「膨胀」从感觉变成数字。全部数字来自本机实测，不是估计。
> 口径：token 用**模型自己的词表**复算（引擎权重目录 `strata-data/packs/swift-iq3xxs/tokenizer/`
> 的 vocab.json + merges.txt + llama.cpp `qwen35` 正则），字节数以 UTF-8 计。

## 0. 一句话结论

每次请求的**固定开销 18,593 tok**（系统提示词 3,782 + 工具定义 14,811），
其中 **44% 的工具近 7 天 0 次调用**（36/69 个，6,484 tok），
系统提示词自身 **62% 被一个自研插件的说明段落占掉**（self-recall 2,363 tok）。
另有**历史膨胀**：AGENTS.md 每次变更就注入一份（2,977 tok），旧份不删——
本会话 26 份 = 93,236 tok；7 天 40 个会话里共 106 份 = 1,239,785 字节。

## 2. 历史膨胀（不进固定开销，但会吃掉窗口）

`dsh-agent-instructions` 发现 AGENTS.md 变化后，会以 user/message 追加一份
`<system-reminder> Updated instructions from: ~/.dsh/AGENTS.md …`（单份 11,537 B / 2,977 tok），
**旧份留在历史里不删**。本会话（session-70c8346c）26 份 = 345,165 B = 93,236 tok。

近 7 天 40 个会话统计：

| 会话 | 注入份数 | 注入字节 | 会话最大上下文 tok |
|---|---:|---:|---:|
| 70c8346c（本会话） | 26 | 345,165 | 699,661 |
| 65c33529 | 19 | 246,664 | 181,067 |

| 5ad0f10d | 4 | 26,641 | 397,017 |
| 合计 40 个会话 | 106 | 1,239,785 | — |

**为什么没被压回去**：本会话 provider `deepseek-official` / model `deepseek-flash`
声明 `contextWindow: 1,000,000`（`request/context` 事件）⇒ 压缩阈值极高，
上下文能涨到 699,661 tok 才触发（本会话压缩过 4 次，末次之后回落）。本机 strata 引擎实际 ctx = 262,144。

## 3. 候选裁切（每项都是独立动作，省多少已算）

| 编号 | 动作 | 省 token/请求 | 需改哪 |
|---|---|---:|---|
| A | self-recall 系统段落搬进技能，提示词只留一行指针 | −2,063 | 自研插件 `~/dsh-self-recall/index.js` |
| B | 关掉 chef MCP（工具 1,186 + 提示词 707） | −1,893 | `cordis.patch.yml` 注掉 insert 块 |
| C | vault 11 工具 → 2（search/get），其余收进技能 | −3,115 | 自研插件（vault 工具注册处） |
| D | 0 次且可整组关：MCP 资源 3 + goal 3 + fork/send + exit_plan_mode + proc_kill + 4 个搜索工具 | −2,008 | 上游插件只能整插件关；自研的改注册 |
| E | 重复注入去重（新注前先删旧份） | 0（省历史） | `dsh-agent-instructions`（上游） |

A+C+D ≈ −7,186 ⇒ 固定开销 18,593 → 11,407 tok。
全做 ≈ −9,079 ⇒ 9,514 tok。

## 4. 复现命令

```bash
# 1) 取当前会话的 header（工具定义）与 system/message（系统提示词）
zstd -dc ~/.dsh/sessions/--home-loong-*strata-engine--/session-70c8346c-*/session.v4.jsonl.zstd > /tmp/sess.jsonl

# 2) 上下文体量的权威来源：每次请求的 usage
grep -o '"cacheReadTokens":[0-9]*' /tmp/sess.jsonl | tail -5

# 3) 模板：本报告用的脚本
#    /tmp/measure.py  /tmp/groups.py  /tmp/costs.py  /tmp/injscan.py  /tmp/buildtok.py
```

> 词表复算的可信度：`hello world` → 2 tok、`你是哪个模型？`(7 字) → 4 tok、
> `def foo():\n    return 1\n` → 9 tok，与 Qwen 系词表行为一致；
> 与实测 `usage` 口径（同一 provider 计数）无冲突项。
