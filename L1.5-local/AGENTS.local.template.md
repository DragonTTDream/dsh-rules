# 个人覆盖层（模板）

> 用法：复制到 `<工作区>/AGENTS.local.md`，加进该仓库 `.gitignore`。
> 本层优先级高于同目录 `AGENTS.md` 与 L0。只写给"你自己"看的东西。

## 我要求的输出格式

- 每条实测结论标出**当时的推理强度/版本等前提**，否则数字没有可比性。
- 汇报只给论点 + 要点表；过程噪音不进正文。

## 我不接受的行为

- 超出我明确点名范围的"顺手统一"。
- 往别人的文档里写东西——要新建就新建。
- 自作主张弹提问框；需要我问，就把选择列在正文里。

## 本机装配（换成你自己的）

- 模型/端口/路径/内存阈值 → 写这里，不要写进公开仓。
