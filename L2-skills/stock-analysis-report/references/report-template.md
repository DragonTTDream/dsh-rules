# 报告骨架（11 节）

> 依据 LangAlpha `impact-analysis/SKILL.md` 的七步，经本机一轮完整实战验证后收敛出的结构（实战标的与结论见工作区报告，**不在本模板内**）。
> 落盘：`<工作区>/股票分析框架/个股分析/<代码>-<名称>-<年月>.md`。**修订原档，不建平行档。**

## 顶部（三行，不可省）

```
**就绪姿态**：`review-ready` —— <点名是哪个数字/输入压低的>
**as-of**：行情 as-of <日期 时刻 时区>；财务 as-of <报告期>；宏观 as-of <日期>；检索 as-of <日期>
**范围**：本档覆盖 <维度>；不覆盖 <明确列出>
```

## 1. 结论（前两句给完）

- 第一句：结论。第二句：什么会改变它。
- 承重数字带标签 + as-of。
- 行动动词只用封闭集：`watchlist` / `wait for proof` / `re-underwrite`，**每个都要写触发点**。

## 2. 事件与时间桶

每个事件一行：`事件 | 宣布日 | 生效日 | 时间桶 | 日期置信度`

- 时间桶封闭集：`immediate` / `this quarter` / `this year` / `structural`。
- 日期置信度：confirmed / scheduled / estimated / reported。
- **宣布日与生效日必须分列**（只有生效日动科目）。

## 3. 传导链（逐条五环，写不满五环就不写这条）

每条链一个小节：

```
| 环 | 内容 |
| 事件 | <带日期与置信度的事实> |
| 渠道 | <渠道表上的名称，一渠道一行> |
| 驱动 | <单位/价格/数量/利率/税/贴现率> |
| 科目 | <封闭集：revenue / gross margin / opex / interest / tax / capex / working capital / share count / 估值输入> |
| 行动 | <谁被迫做什么，什么条件下> |
| 时间桶 | <四选一> |
| 阶次 | direct / second / third |
| 定量来源 | <能算出来的披露；未披露就写"未披露"> |
```

## 4. 效应阶次（分栏写，永不混算）

| 阶次 | 定义 | 允许给什么 |
|---|---|---|
| direct | 与披露同强 | 方向 + 幅度 |
| second | 第三方行为（船公司/供应商/客户/竞争对手） | 方向 + 幅度，**必须低于直接项** |
| third | 两道以上中介 | **只给方向，不给幅度** |

## 5. 暴露表（一渠道 × 一名称 = 一行，永不合并）

| 事件 | 渠道 | 首个科目 | 滞后（与缓冲） | 阶次 | 方向 | 定量来源 |
|---|---|---|---|---|---|---|

## 6. 已定价 vs 需要证据（本节最容易被滥用）

| 主张 | 定价证据 | 判定 |
|---|---|---|

**门槛**：判"已定价"必须给出**该主张落地后的价格行为证据**（涨跌幅 + 量能 + 同板块对照 + 是否交易日）。给不出 → 判"需要证据"，并写明**判定点是哪一天、看什么**。

**"利好兑现"是"已定价"的退化形态** —— 无证据时不许写。

## 7. 监测表（复判触发器，每行五字段齐全）

| 指标 | 阈值 | 来源 | 日期/窗口 | 两侧动作 |
|---|---|---|---|---|

**门槛**：读数 + 阈值 + 动作三者齐备，且能说清哪个输入会因此改变 → 才立为监测项。阈值必须带数字与日期。**两侧动作 = 证实侧与证伪侧都要写。**

## 8. 最强反方

写出能推翻本结论的最强论证，并写明它现在为什么没被采纳（不是"它不重要"，是"它缺什么证据"）。

## 9. 缺失证据

| 缺什么 | 为什么缺 | 缺了会怎样 | 用户可以怎么给 |
|---|---|---|---|

**交付前 `needs-source` 必须消失**：要么找到来源，要么删掉该主张。取数失败写在这里，**不用替代值填**。

## 10. 数据与来源台账

- 本机取数：工具名 + 参数 + 时刻 + 成功/失败。
- 检索来源：带链接的分组清单（按主题分组）。
- 冲突登记表（若有）。

## 11. 边界（不做什么）

固定写：

- 不给买卖点位、仓位、止损；不构成投资建议。
- 不预测股价；价格只作为"市场信念"读取。
- 机构目标价属 `street estimate`，多档口径不一致时明写"不能当一致预期用"。
- 未覆盖的维度明确列出。
