# 证据与来源纪律

> 转写自 LangAlpha `research-conventions/references/evidence.md` 与 `SKILL.md`（Apache-2.0），按本机数据层适配。
> 本文件是**判据本体**：SKILL.md 的 Step 6 指向这里取标签与姿态，不在 SKILL.md 里重复定义。

## 1. 七个证据标签（封闭集；每个承重数字带一个）

| 标签 | 标记什么 | 必须附带 |
|---|---|---|
| `fact` | 原始文件里报告过，或数据工具返回已收盘期间的值 | 文件或工具调用 |
| `company claim` | 公司对自己的陈述，无独立方证实（指引、市占率、可及市场） | 场合 + 日期 |
| `street estimate` | 一致预期或单一分析师数字 | **vintage** + 估算者/分析师数 |
| `model-derived` | 由带标签输入算出 | 输入 + 公式；解出的值还要写目标与重解条件 |
| `judgement` | 我们的观点，非测量 | 一句话理由 |
| `assumption` | 无证据但工作需要而选定的输入 | 依据 + 答案对它的敏感处 |
| `needs-source` | 想要但没有的数字 | 搜过什么、什么能补上 |

`needs-source` 是**起草标签**，交付前必须消失：要么找到来源，要么按 §8 无源主张规则删掉该主张。

## 2. 就绪姿态梯（五档，从表里读，不从上一版加减）

| 姿态 | 成立条件 | 被压低的原因 |
|---|---|---|
| `decision-grade` | 每个承重数字都有来源且在新鲜度阈值内，下行机制清楚，推荐动作所需输入在手 | 任一承重数字过期/无源/有争议 |
| `review-ready` | 分析完整且带来源，还有一项检查或输入未闭合 | 承重主张上有未解冲突，或某项检查未过 |
| `screen-grade` | 覆盖刻意薄，且档里写明 | 头条结论跑在覆盖前面 |
| `not-ready` | 承重主张无来源/过期/有争议且无东西能定，结论压在它上 | 已是下限；写明什么能抬升 |
| `blocked` | 输入根本取不到（工具失败、未披露指标、没有的文档） | 已是下限；点名缺什么、什么能解锁 |

**规则**：低于 `decision-grade` 必须点名是哪个数字/输入造成的；承重的未解冲突读作 `not-ready`；取数接口根本取不到读作 `blocked`（不是 `not-ready`）。

## 3. 来源层级（按主张家族分层，全局一套层级不够用）

**公司财务、分部与估值**
1. 财报原文（年报/中报/季报/公告 PDF）——最高层。
2. 数据工具归一化序列与比率（本机 = DSA `get_fundamental_context`）。
3. 一致预期、评级分布、目标价。
4. 公司自己的投资者材料 → 标 `company claim`。
5. 第三方媒体摘要 → 标出处。

**财报压过路演 PPT，PPT 压过新闻摘要。** 工具数字与财报冲突时，**财报是数字，工具数字是"归一化差异"，要点名写出来**。

**市场、持仓、资金面**
1. 实时报价（本机 = DSA `get_realtime_quote`，注意非交易日返回上一收盘）。
2. 日线历史（本机 = `get_daily_data` / `探测-异动定位.py`）。
3. 龙虎榜、筹码、板块归属。
4. 北向/南向：**个股净买入已停披露**（见 `data-layer.md`）。

**文章里引用的价格，日期属于那篇文章。** 用它作"被报告过"的证据，价格本身要从价格工具取。

**宏观与利率**
1. 官方序列（本机 = FXMacroData 免 key 客户端，72 操作 + USD 发布日历）。
2. 发布日历与"尚未公布项"。
3. 发布机构原文（需要定义、修订状态、脚注时）。
4. 对序列的评论 → 标为评论，**永不标为序列本身**。

**事件与带日期事实**
1. 原始文件：协议、公告、监管决定、会议记录。
2. 公司/发行人公告。
3. 财报日历与经济日历（排期日期）。
4. 新闻报道：带出处、时间，并把日期置信度写成 confirmed / scheduled / estimated / reported。

## 4. as-of 与新鲜度

**每个数字带 as-of**：数字为真的那个时刻，**不是取数的时刻**。两者不同就都记（今日取的一季持仓，as-of 是季末）。

| 数据 | 新鲜期 | 何时刷新 |
|---|---|---|
| 盘中价、报价、指数、FX | 盘中一分钟内 | 任何"当前水平"的陈述 |
| 收盘价、市值、一切建立在价格上的倍数 | 取数当日 | **次日开盘** |
| 一致预期 | 7 天 | 财报、预告、指引变更 |
| 已报财务 | 到下一次预定披露 | 后续文件或重述 |
| 公司指引 | 到下一次指引事件 | 任何修订它的文件或电话会 |
| 持仓与机构持股 | 所报季度 | 下一个披露窗口 |
| 宏观序列 | 到下一次预定发布 | 发布，以及对历史值的修订 |
| 行业规模与份额研究 | 12 个月，**必须带 vintage** | 更新的研究，或市场结构变化 |
| 新闻与事件主张 | 当日 | 任何后续头条能承载的发展 |

**六个过期态**（布尔值会让"超阈值一分钟"和"超阈值两季"读起来一样）：

- `live`：阈值内且本轮核验。
- `current`：阈值内，本会话早前取。
- `aging`：超阈值，方向仍可用 → **在数字旁说明**。
- `stale`：超阈值且承重 → 刷新，否则撤掉它支撑的主张。
- `superseded`：有更新值/文件/修订 → 用新的；读者可能见过旧的，要说明旧的已被取代。
- `unknown`：as-of 建立不起来 → 当 `needs-source` 处理。

**本机实例**：`realtime_quote` 在星期日返回上一交易日收盘 → 它是 `current`（as-of 上一交易日），**不是 `live`**。

## 5. 冲突登记（两源冲突要写登记，不许静默取一）

四步：确认两数测同一件事同一期间 → 用该家族的层级 → 记下行 → 写明什么能定案。

| 主张 | 来源 A 与值 | 来源 B 与值 | 选用 | 理由 | 什么能定案 |
|---|---|---|---|---|---|

两条护栏（两种失败在成品里都看不见）：**两源平均出来的数字是"没有谁报告过的第三个数"**；静默选取让读者分不清"已解决的冲突"和"没注意到的冲突"。**把选择展示出来。**

同层级且无东西能定 → 两个值都留，起草时标 `needs-source`；若承重，按姿态梯重选姿态（**承重的未解冲突读作 `not-ready`**）。

## 6. 证据 → 语言（散文的信心跟着证据走）

| 主张背后是 | 写成 | 你还不能用 |
|---|---|---|
| 两个以上顶层来源一致 | 直陈 + 章节来源注 | 无 |
| 一个顶层来源 | 直陈并就地指名来源 | "已确认"、"多方来源" |
| 公司自述无独立证实 | "公司报告"、"管理层指引至" | 把该数字写成结果 |
| street estimate | "N 位分析师一致预期为"，带 vintage | 不指名就说"将会/预计" |
| 我们自己的模型 | "我们的模型意味着"，展示输入 | "公允价值是 X"、无区间的点目标 |
| judgement | "我们认为/我们的读法是"，带理由 | "显然"、"市场错了" |
| assumption | "假设 X，则 Y"，带敏感度 | 未打标签就进头条 |
| 什么都没有 | **该主张不出现** | 该主张的软化版 |

**精度也跟证据走**：由假设导出的数字最多写两位有效数字；**你实际知道的是区间时，写区间，不写点值。**

## 7. 读者可见标签（工作表用标签法，交付物印读者的词）

`fact` → **reported** ｜ `company claim` → **management statement**（公司自定义指标用 company-defined）｜ `street estimate` → **consensus of N analysts**（带 vintage；单人则指名分析师）｜ `model-derived` → **our estimate**（幻灯片里用 derived）｜ `judgement` → **our judgement** ｜ `assumption` → **assumed** ｜ `needs-source` → **永不打印**：交付时它要么变成来源，要么主张消失。

## 8. 无源主张规则

**承重 = 去掉它就改变结论。** 真正搜过仍无支撑，只有两条出口：

- **删掉主张，连带删掉压在它上面的所有结论。这是默认出口。**
- 保留并标 `assumption`，写明什么能证实它，并重选姿态（压在假设上的结论读作 `not-ready`；档自称薄版时读 `screen-grade`）。

**软化措辞是"发货一个错答案"的出口** —— 对冲语在下游所有人眼里都读作知识。**要删，或降级，不要软化。**

## 9. 缺口怎么写（三种形态，各给一句诚实而非"谨慎"的话）

- **来源稀薄**：把已有覆盖对着想要覆盖写。「五家同业中两家披露该指标；表覆盖这两家，其余标注未披露。」
- **来源冲突**：把登记的选用写成一句。「我们用 10-Q 的 X；投资者材料显示 Y，其口径还包含 Z。」
- **精度无支撑**：给边界不给点值。「分部毛利率未披露；与已报总额一致的区间是 A 到 B。」

## 10. 引用密度

- **散文**：每节一条来源注（写明该节压在哪些工具与文件上）+ 读者会质疑的主张给行内引用。**每格都塞引用会把真正重要的埋掉。**
- **表格**：每个输入一条来源注（整表一条注定位不了任何东西）。
- **幻灯片**：每张数据页一行来源，且要能在导出后存活。

## 11. 永远带时间戳（出现即带 as-of）

价格、市值、企业价值、一切建立在价格上的倍数、指数水平、汇率、收益率与利差、空头持仓、借券、期权快照与隐含波动、一致预期、持股比例，以及**任何含"目前/今天/现在"的句子**。
