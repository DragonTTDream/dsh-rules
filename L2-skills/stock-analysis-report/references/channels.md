# 传导渠道表

> 转写自 LangAlpha `impact-analysis/references/channels.md`（Apache-2.0），按本机 A股/港股场景适配。
> 用法：写传导链时逐渠道取四字段。**渠道不在表上时，先按同四字段建条目，再写主张；滞后追不到具名缓冲的渠道 = 对时间的猜测，不发货。**

## 四字段（渠道表就是暴露表要的四列）

| 字段 | 含义 |
|---|---|
| **Reaches first** | 最先到达的科目 |
| **Lag** | 滞后多久 + 决定它的**缓冲**是什么 |
| **Tell** | 在财报出来之前就动的前兆信号 |
| **Sizes from** | 把主张变成数字所需的披露 |

**滞后不是事件的属性，是"事件与科目之间缓冲"的属性** —— 这就是同一次冲击两家公司隔两个季度报告的原因。

**一渠道 × 一名称 = 一行。** 一次冲击通常同时走 2–3 条渠道，符号不同、滞后不同 → 暴露表里**拆成多行，永不合并**。

## 1. Rates and discounting（利率与贴现）

- **先达**：**倍数，同日，不经任何科目**（贴现率是估值输入，不是经营成本）。然后是浮动利率债务的利息支出与窗口内再融资的部分，再是 capex（通过门槛利率），再是营运资金融资成本。对银行/放贷方先达净利息收入，符号取决于存款 beta 而非方向。
- **滞后**：倍数当动。利息支出在下次重置/到期动（按固定浮动比，数季到数年）。capex 决策 1–3 季后，capex 支出更晚。
- **tell**：利息支出附注里的**加权平均利率先动**（早于总额）；再融资被提前/推迟；回购放缓而循环信贷被提取。
- **定量来源**：债务附注，特别是到期表与浮动利率占比。

**本机适配**：A 股贴现率锚中国利率，美债对 A 股是二阶；对 H 股（港股通/外资定价）是一阶。

## 2. Input costs（输入成本）

- **先达**：COGS → **gross margin**，此时 revenue 完全没动。输入是生产外的劳务/能源时，opex 第二。
- **滞后**：库存周转 + 合约覆盖。持 90 天库存且签年度供货合约的公司，在新成本存在后仍背 2–3 季旧成本。
- **tell**：单位成本上升且库存天数同步上升；销售成本评论**首次点名**该输入；**提价公告是"试图传导"，不是传导本身**。
- **定量来源**：该输入占销售成本的比例（直接披露，或由分部与成本结构附注导出）。

## 3. FX（两个行为不同的子通道，拆开再定量）

- **Translation（折算）**：境外结果折算回报告货币 → 达报告收入与报告利润，**无现金后果、无毛利率效应**。
- **Transaction（交易）**：成本与收入分处不同币种 → 达 **gross margin**，是真钱。
- **滞后**：折算在下一报告期落地。交易随对冲簿滚出，典型 2–4 季；**12 个月滚动对冲可整年不显**。
- **tell**：固定汇率增速与报告增速背离；对冲附注的名义与期限变化；销量不变而因汇率修订指引。
- **定量来源**：分地区收入 vs 成本地 footprint + 对冲附注的名义/期限/汇率。

## 4. Demand（需求）

财政变化、信心冲击、触及家庭的利率变动、开放/关闭一个市场的规则。

- **先达**：revenue（通过 units）。gross margin 第二（经营杠杆 + 销量不及预期时的折价）。working capital 第三（为旧需求下的库存撞上新的）。
- **滞后**：耗材与日用品是数周（货架是缓冲）。有 backlog 隔离报表处是数季到数年 —— 这就是工业企业能在需求冲击第一年报告创纪录收入的原因。
- **tell**：**订单/出货比先于收入转**；渠道库存累积；促销节奏变化；单位增长与价格增长背离。
- **定量来源**：披露的量价拆分、backlog 及其覆盖期、终端市场收入结构。

**本机适配**：汽车 = 经销商库存预警指数 + 库存系数 + 降价车型数 + 量价背离。

## 5. Regulation and policy（监管与政策）

规则、审批、补贴、税变、反垄断。

- **先达**：**由工具本身决定，不由行业决定**。补贴达 revenue 或 capex；税变达税项；合规规则达 opex 与 capex；市场禁入/许可直接达 revenue。
- **滞后**：**最长且最可变** —— 宣布日与生效日是两个事实，**只有第二个动科目**。评论期、过渡条款、分阶段、诉讼全在中间；**倍数常在宣布时动，科目等数年**。
- **tell**：规则文本里的生效日与过渡条款；公司**风险因素措辞在两次披露之间变化**；opex 里出现合规线；游说或诉讼披露。
- **定量来源**：规则文本自己的范围（覆盖产品、阈值、税率）vs 公司分部披露。

## 6. Supply chain（供应链）

中断、产能损失、物流约束、出口管制。

- **先达**：**revenue，通过发不出去的 units**。Cost 第二（加急运费与现货舱位）。**先抓 cost 是这里的常见错误，会把冲击记晚一个季度。**
- **滞后**：无缓冲处即时；有库存或双供应处 1–2 季。
- **tell**：交期拉长；成本评论点名加急与现货运费；**供应商自己的指引先动**；库存降而 backlog 升。
- **定量来源**：供应商与地域集中度披露、单一来源风险因素、库存 vs 正常周转。

## 7. Credit conditions（信贷条件）

放贷标准、利差走阔、融资市场关闭。

- **先达**：借款人的利息支出与再融资能力。capex 第二。**revenue 第三** —— 对"客户融资购买"的公司，这是影响最大且最不被预期的地方。
- **滞后**：利差即时；借款人在下次融资需求处感到；对融资消费品的需求效应在标准收紧后 1–2 季。
- **tell**：放贷标准与信贷条件序列；发行日历变安静；循环信贷被提取、回购取消、分红持平；**汽融/融资租赁通过率下降**。
- **定量来源**：到期表 vs 窗口内融资需求 + 赊销/自有金融臂贡献的收入占比。

**行业适配**：制造/零售类看厂商自有金融臂（汽融、融资租赁、保理）的年化利率与审批通过率；经销/渠道型看经销商库存融资与授信收紧。

## 8. Commodity pass-through（商品传导）

油、气、金属、农产品价格变动。**最常被并成一行、而至少该拆两行的渠道** —— 同一事件让生产者与消费者反向、按不同时钟动。

- **先达**：生产者 = revenue（通过实现价格）。消费者 = COGS。**规制公用事业/代工方都不达**（合约或关税把成本直接传导过去，只有 working capital 动，此时"敞口"主张通常是错的）。
- **滞后**：生产者约一季（实现价按合约滞后于现货）。消费者 = 对冲簿期限。传导型标的只在合约重置慢于价格变动处显效。
- **tell**：实现价对现货基准的披露；对冲附注；**燃油/材料附加费出现或被撤销**；规制费率申请。无现货判断时，用公开生产者价格序列作代理并**标为代理**。
- **定量来源**：生产者 = 产量 vs 实现价；消费者 = 商品占销售成本比例；两者 = 对冲名义与期限。

**拆行示例（抽象）**：一次"航运附加费上调"事件同时命中渠道 6（Supply chain，先达 revenue，通过发不出去的 units）与渠道 8（Commodity pass-through，消费者侧达 COGS）→ 暴露表里**两行，符号与滞后各写各的，永不合并**。

## 9. 表上没有的渠道

按同四字段建条目再写主张：点名首个科目 → 从具名缓冲取滞后（库存周转、合约长度、重置日、监管生效日、对冲期限）→ 找一个先于财报动的可观察 tell → 点名能定量的披露。**滞后追不到具名缓冲 = 对时间的猜测。**
