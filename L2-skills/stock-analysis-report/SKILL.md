# 个股分析报告生产线（stock-analysis-report）

> 版本 v2.0 ｜ 依据：本机部署的 `daily_stock_analysis`（DSA，MIT）数据层实测 + LangAlpha 方法论 11 个技能（Apache-2.0，见工作区 `部署-dsa/方法论补丁/来源声明.md`）+ 一轮完整实战踩坑记录。
> **定位：数据层出数据，模型出检索与判断。** 不要跑 DSA 的 LLM 流水线写报告——它不联网检索，写不出传导链与证据标签。

**什么叫"专业"：** 一份分析专业与否，不看覆盖了多少新闻，看**每个承重数字能不能追到来源与 as-of、每条冲击能不能落到一个具名科目、每个结论能不能被一个带日期的观察推翻**。三者缺一，就是叙事，不是分析。

## 内容边界（本技能自身的红线）

**本技能只写判据与接口级事实，不写个股结论、不写时效性事件。**

| 允许写进本技能 | 禁止写进本技能 |
|---|---|
| 判据（"同日同板块龙头涨幅聚集在 1pp 内 → 板块 β"） | 某标的的具体涨幅、具体归因结论 |
| 接口级事实（"北向个股净买入 2024-08-19 起停止披露"） | 某标的的具体数据（销量、毛利率、目标价） |
| 工具行为（"非交易日返回上一交易日收盘"） | 时效性事件（某附加费某日生效、某规划某日印发） |
| 结构与门槛（报告骨架、监测表五字段） | 某轮的监测表内容、某轮的判定点日期 |

**个股案例与时效结论只进工作区报告**（`<工作区>/股票分析框架/个股分析/`），本技能最多留一句指针。理由：**写进技能的个股结论会在下一次分析里变成噪音，写进技能的时效事件会随时间变成假事实。**

**自检**：改完本技能后 grep 一遍具体标的名与具体日期，命中即删。

## Step 1 · 定范围

定四件事，缺哪件就问哪件，不要用假设填：

- **标的与代码格式**（A股 6 位 / 港股 `hk` 前缀 / 美股代码 / 指数）。
- **时间窗**：这次要回答的是"现在怎么看"，还是"某个已发生的变化怎么看"。
- **要回答的问题**：一句话写下来（全维度？归因？支撑与风险？权威评级？）。
- **是否复判**：有既有报告 → 走修订路径，读它的监测表作为本轮输入。

**Done when**：四件事都写进报告顶部，且"要回答的问题"是一句可被推翻的句子，不是"分析一下"。

## Step 2 · 取数

```bash
cd "<部署根>" && .venv/bin/python 探测-数据层.py <代码>      # 全量数据 → JSON
cd "<部署根>" && .venv/bin/python 探测-异动定位.py <代码>    # 日线 → CSV
cd "<部署根>/repo" && ../.venv/bin/python main.py --dry-run --stocks <代码> --no-notify --force-run
```

命令、参数、实测行为、失败模式全在 `references/data-layer.md`。**部署根路径从工作区 README 指针解析，不要写死。**

**Done when**：每个承重字段**要么有值（带来源与 as-of），要么记为缺口**；缺口写进报告"缺失证据"节，**不得用替代值填**，不得写成"无数据即无现象"。

## Step 3 · 核验与定位（三条硬规矩在此执行）

1. **核验交易日**：`date '+%Y-%m-%d %A'`。非交易日 → 报价 as-of 是上一交易日，**不是"今天"**。
2. **报价与日线末行比对**：price / change_pct / volume / volume_ratio 逐位一致 → 它是收盘数据（`current`），**不是 `live`**。
3. **异动定位**：算逐日涨幅，找出异动日；核验该日是否交易日。归因前先定位，**不猜**。

**归因判据**（问"暴涨/暴跌什么关联"时）：

- 取同板块 2–3 只龙头**同日**涨幅：聚集在 1pp 内 → 板块 β；该标的显著跑赢 → 才有个股 α 归因空间。
- 大盘跌而该板块涨 → 主题资金选主线，不是资产重定价。
- 催化时间链要连得起来（印发日 → 发酵日 → 爆发日）。
- 归因错了公开修正，写四列表：上轮写法 / 实际 / 错误类型 / 根因。

**Done when**：报告里每个价格陈述都能追到"哪一天 + 是否交易日 + 哪个工具取的"。

## Step 4 · 分轮检索

按问题选轮次，每轮带出处与日期：

| 轮 | 检索什么 | 用哪个工具 |
|---|---|---|
| 1 | 产业链上下游、自身环节 | `advanced_search` |
| 2 | 销量/经营数据与结构（分品牌/分地区/量价拆分） | `advanced_search` + 时间过滤 |
| 3 | 地缘与政策（战争、航运、关税、补贴） | `advanced_search` |
| 4 | 宏观与利率（政策利率、长端国债、加息概率） | `advanced_search` |
| 5 | 资金面（龙虎榜、融资、机构行为；**北向个股净买入不可得**） | 数据层 + 检索 |
| 6 | 权威评级与目标价（机构名 + 日期 + 定价口径） | `advanced_search` + `web_fetch` 取原文 |

**权威分析限制**：目标价一律标 `street estimate` 带 vintage 与机构名；多档口径不一致要明写"不能当一致预期用"；宏观层外资观点是背景项不是个股评级；目标价不转述为"应该买"。

**Done when**：每个承重主张有出处 + 日期；原文类主张（协议条款、规则文本）已 `web_fetch` 取到原文，不是只拿到摘要。

## Step 5 · 组织传导链

每条冲击写满五环，**写不满五环就不写这条**：

**事件 → 渠道 → 驱动 → 科目 → 行动**

- **科目封闭集**：revenue、gross margin、opex、interest、tax、capex、working capital、share count，以及估值输入本身（贴现率/倍数）。说不出落在哪个科目的冲击是"对主题的情绪"，不发货。
- **一渠道 × 一名称 = 一行**：一次冲击常走 2–3 条渠道，符号与滞后不同 → 暴露表拆多行，**永不合并**。
- **宣布日 ≠ 生效日**：只有生效日动科目。
- **完全被预期的冲击到达科目，永不到达价格。**
- **阶次分栏，永不混算**：direct（与披露同强）/ second（第三方行为，必须低于直接项）/ third（两道以上中介，只给方向不给幅度）。

**Done when**：每条链五环齐全、科目落在封闭集、宣布日与生效日分列、暴露表无合并行。

## Step 6 · 标证据与定姿态

- 每个承重数字带一个标签（七标签封闭集，见 `references/evidence.md` §1）。
- 两源冲突 → 写冲突登记行，**展示选择，不静默取一**；两源平均 = 造出"没有谁报告过的第三个数"，禁止。
- 无源承重主张 → 删掉主张与压在它上面的结论（默认出口），或标 `assumption` 并重选姿态。**软化措辞是发货错答案，禁止。**
- 姿态从 `references/evidence.md` 的姿态梯**重读**得出，不从上一版加减；低于 `decision-grade` 必须点名是哪个数字/输入压低。

**Done when**：交付物里**无 `needs-source` 残留**（要么变成来源，要么主张消失）；姿态写在顶部并点名缺口。

## Step 7 · 落盘、监测表、台账

- 报告按 `references/report-template.md` 的 11 节写，进 `<工作区>/股票分析框架/个股分析/<代码>-<名称>-<年月>.md`；**修订原档**。
- **监测表每行五字段齐全**：`指标 | 阈值 | 来源 | 日期/窗口 | 两侧动作`。阈值必须带数字与日期；两侧动作 = 证实侧与证伪侧都写。只有"读数 + 阈值 + 动作"齐备且能说清哪个输入会因此改变，才立为监测项。
- 每次 create/move/delete 追加一行到 `/tmp/dsh-work/<session>/manifest.tsv`：`时间 \t 操作 \t 绝对路径 \t 交付物|中间物`；收尾按台账清理，中间物压缩结论后删除。
- 新目录登记进工作区 README 文件地图。

**Done when**：监测表可直接回答"什么时候该回来复判、看什么、什么算证实、什么算证伪"；台账已登记。

## 收尾统一验收（hard checks，逐条过，不过就点名）

1. 每个承重数字有标签 + as-of，且 as-of 在新鲜度阈值内（超阈值要标 `aging`/`stale`）。
2. 每条冲击链五环齐全，科目落在封闭集内。
3. 无 `needs-source` 残留；无软化措辞冒充证据。
4. 就绪姿态在顶部，且点名了压低它的那个数字/输入。
5. 监测表每行五字段齐全，阈值带数字与日期。
6. 边界节存在：不给买卖点位/仓位/止损，不预测股价，行动动词只用 `watchlist` / `wait for proof` / `re-underwrite` 且各带触发点。
7. 本技能自检：grep 具体标的名与具体日期，命中即删。

## 常见不合格形态（11 条，逐条是"什么形态算不合格"）

| 形态 | 为什么不合格 |
|---|---|
| 冲击说不出落在哪个科目 | 那是主题情绪，不是传导 |
| 把宣布日当生效日 | 只有生效日动科目；会把冲击记早 |
| 非交易日报价当"今天涨了 X%" | as-of 错，整条归因链跟着错 |
| 两个来源取平均 | 造出没有谁报告过的第三个数 |
| 静默选一个来源 | 读者分不清"已解决"与"没注意" |
| 软化措辞代替删主张 | 对冲语在下游所有人眼里读作知识 |
| 多档目标价当一致预期 | 口径不同、vintage 不同 |
| 取数失败写成"无资金异动" | 把数据缺口写成了市场结论 |
| 监测项无阈值/无日期 | 触发器不可执行，等于没写 |
| "已定价/利好兑现"无价格行为证据 | 无证据的定价判定 |
| direct/second/third 混算成一个数 | 把第三方行为与披露同权 |
