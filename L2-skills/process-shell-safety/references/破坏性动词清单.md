# 破坏性动词清单（铁律 6 的细节层）

> 何时读：要跑、或要写含下列任一类动作的脚本前。正文只留「逐命令批准」这条纪律，清单本体在这里。

下列命令**不因"任务里提过"而获得授权**，每条都要先报出**确切命令 + 影响面**，得到用户点头再跑。

| 类别 | 清单 |
|---|---|
| 递归强删 | `rm -rf` / `rm -fr` / `rm --recursive --force`（**任意顺序**）；`rm -rf $VAR`（**变量未校验**即禁）；`find … -delete` / `-exec rm` |
| git 丢弃 | `git reset` / `revert` / `checkout` / `restore` / `clean -f` / `switch -f` / `switch --discard-changes` / `stash drop\|clear\|pop` |
| 包与系统 | `dnf remove` / `rpm -e`（本机 2026-09-23 内核事故即此类，见工作区《内核删除事故报告.md》）、`npm/yarn/pnpm/bun audit fix --force` |
| 磁盘与进程 | `dd` / `mkfs` / `fdisk` / `format`；`killall -9`；fork bomb（`:(){ :|:& };:`） |
| 数据 | **无 WHERE 谓词的 `DELETE` / `UPDATE`**、`DROP`、`TRUNCATE`、schema 迁移与截断 |
| 密钥与配置 | 提交 `.env`/私钥、把明文密钥写进代码/日志/commit、关闭 SSL/证书校验、直接改 `.git/` 内部、执行未知来源脚本 |
| 无界遍历 | 对 `~`、`/home/loong`、配置目录做无界递归删除/遍历 |

## Never 级（确认也不豁免）

`rm -rf $VAR` 未校验变量 · 明文密钥外流 · 无谓词的 `DELETE/UPDATE` · 关证书校验 ·
执行未知来源脚本 · 直接改 `.git/` 内部 · 无界递归遍历 home/配置目录。

## 授权粒度

- **类别授权 ≠ 逐文件授权**："清理一下产物"只覆盖未跟踪的临时物；删已跟踪文件仍要逐个问。
- **一次批准不延伸到下一次**。
